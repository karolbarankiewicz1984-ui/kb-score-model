# Audyt A/B/C

Codziennie: rozliczać wyłącznie niezmienne prognozy sprzed rozpoczęcia meczu; sprawdzać identyfikację spotkań i dostępność wyników. Osobno A, B, C oraz każdy rynek: liczba propozycji, rozliczonych i nierozliczonych, skuteczność, Brier, log loss. Weryfikować 1X2 z obu modeli i rynki dodatkowe. Nie traktować braku wyniku jako nietrafienia.

Co tydzień: PDF z trendami i kontrolą kalibracji. Pierwszy przegląd decyzyjny dopiero po 100–150 unikalnych rozliczonych meczach. Żadnych automatycznych zmian progów ani modelu produkcyjnego.

Stan: plan, niepotwierdzone wdrożenie automatycznego audytu A/B/C.
