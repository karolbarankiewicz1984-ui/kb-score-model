# Data / Lineup Signal

Aktywne od 27.09.2026 jako warstwa kontrolna KB Score 2.1.

## Data Quality
- **A** — oficjalny skład, oficjalny komunikat klubu / ligi / federacji lub bezpośrednio potwierdzony fakt.
- **B** — kilka zgodnych wiarygodnych źródeł bez oficjalnego potwierdzenia.
- **C** — pojedyncze lub niepewne doniesienie albo przewidywany skład.

## Lineup Risk
- **LOW** — kluczowe statusy stabilne.
- **MED** — istotne, lecz ograniczone niewiadome.
- **HIGH** — niepewność kluczowych zawodników, bramkarza, rotacji lub późnego XI może zmienić tezę.

## Zasada
Data C lub Lineup HIGH może zablokować PLAY.

Warstwa Data/Lineup:
- nie zmienia mechanicznie P(model),
- nie zmienia P(cal),
- nie zmienia Sport Score,
- wpływa na Confidence i decyzję.

Priorytet źródeł:
1. oficjalne kluby / ligi / federacje,
2. FotMob / SofaScore / Flashscore,
3. Transfermarkt pomocniczo,
4. Reuters / BBC / Sky i wiarygodne media lokalne.
